# План реализации

Спека: `docs/superpowers/specs/2026-08-10-telegram-shop-bot-design.md`

Порядок выбран так, чтобы каждый следующий этап опирался на уже проверенный предыдущий, а
самые опасные места (деньги, выдача товара, доступ) закрывались тестами раньше, чем на них
навешивается интерфейс.

## Этап 1. Основание

- `requirements.txt`, `.env.example`, `.gitignore`, `docker-compose.dev.yml`
  (MySQL 8.4 и Redis на отдельных портах, чтобы не конфликтовать с системными).
- `bot/config.py` — настройки из окружения, валидация при старте.
- `bot/logger.py` — JSON-логи, отдельный поток для платежей.
- `bot/utils/money.py` — копейки, форматирование, округление скидки.

Проверка: `pytest tests/test_money.py`, юнит-тесты округления и границ.

## Этап 2. База

- `bot/db/models.py` — 19 таблиц по спеке.
- `alembic/` — первая миграция.
- `bot/db/session.py` — фабрика сессий.
- `deploy/check-migrations.sh` — накат → повтор → откат → сверка схемы → повторный накат.

Проверка: полный цикл миграций на настоящей MySQL, снимок схемы совпадает побайтно.

## Этап 3. Репозитории и сервисы без Telegram

- `bot/repo/*` — доступ к данным.
- `bot/services/` — `catalog`, `stock`, `orders`, `delivery`, `promo`, `balance`,
  `refunds`, `access`, `texts`, `settings`, `stats`.
- Сидинг текстов и настроек значениями по умолчанию.

Проверка: тесты бизнес-правил на настоящей MySQL —
резерв позиций при параллельных покупках, идемпотентность выдачи, атомарность счётчика
промокода, сходимость леджера баланса, отказ по умолчанию в проверке доступа.

## Этап 4. Платежи

- `bot/payments/base.py` — интерфейс провайдера.
- `platega.py`, `cryptobot.py` — клиенты.
- `bot/services/payments.py` — `confirm_order`: единственная точка подтверждения.
- `poller.py` — фоновая сверка незавершённых заказов.
- `webhook.py` — приём callback'ов, проверка подписи CryptoBot, сверка секрета Platega.

Проверка: тесты на поддельный callback, на расхождение суммы, на повторное подтверждение,
на «оплачено, но склад опустел».

## Этап 5. Пользовательская часть

Старт, проверка подписки, каталог, карточка товара, выбор количества, промокод, выбор
способа оплаты, проверка оплаты, выдача, профиль, баланс, история покупок, поиск,
информация.

## Этап 6. Админ-панель

Категории, товары, склад (заливка пачкой, партии, брак), заказы (список, поиск по ID
заказа и Telegram ID, карточка, замена, возврат, блокировка), промокоды, рассылки,
статистика, тексты, настройки, каналы, администраторы, выгрузка XLSX.

## Этап 7. Оснастка и сдача

- `deploy/run-tests-gate.sh` + `deploy/test-baseline.txt`.
- `scripts/mutate.py` и прогон по четырём якорям.
- `README.md` — установка, `.env`, запуск, деплой.
- Приватный репозиторий, коммит.

## Не входит

Живой платёж и деплой на сервер — после получения доступов и сервера; выполняется по
команде владельца, не по инициативе разработчика.
