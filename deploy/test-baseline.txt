# Известные падения тестов.
#
# У каждой строки обязан быть комментарий: ПОЧЕМУ она здесь и что нужно, чтобы
# её убрать. Строка без объяснения через месяц становится вечной.
#
# Правила:
#   * линия должна сокращаться — рост допустим только с --force-grow="причина";
#   * --update нельзя применять к падению, которое не разобрано: среди
#     «протухших» падений регулярно прячутся настоящие дыры;
#   * цель — RC=0 три прогона подряд, а не один: тест, падающий раз из трёх,
#     делает гейт случайно красным, а случайно красный гейт перестают читать.
#
# На момент сдачи линия пуста: все 78 тестов зелёные три прогона подряд.
